data-slot=\"markdown-preview\"><!--[0--><!--np04vi--><h1>隐私政策</h1>
<p>我们重视你的隐私。本页面说明 Life@USTC 如何收集、使用和保护你的信息。</p>
<h2>1. 我们收集的信息</h2>
<ul>
<li>
<p>账户信息：如姓名、用户名、头像和你绑定的登录方式。</p>
</li>
<li>
<p>使用数据：如页面访问、功能操作和错误日志，用于改进服务质量。</p>
</li>
<li>
<p>你主动提交的内容：如评论、作业信息和上传文件。</p>
</li>
<li>
<p>通过 Google Analytics 的 Google 代码（gtag.js）收集的分析数据，包括页面浏览量、会话时长、客户端标识符和基本设备/浏览器信息。我们不会有意向 Google Analytics 发送姓名、邮箱等个人身份信息。</p>
</li>
</ul>
<h2>2. 信息的使用方式</h2>
<ul>
<li>
<p>用于提供核心功能，例如登录、课程与班级信息展示、评论与上传。</p>
</li>
<li>
<p>用于安全与防滥用，例如检测异常行为和防止恶意请求。</p>
</li>
<li>
<p>用于产品改进，例如分析常见问题与优化体验。</p>
</li>
<li>
<p>通过 Google Analytics 分析汇总使用模式，帮助我们了解哪些功能最常被使用以及应在何处重点改进。</p>
</li>
</ul>
<h2>3. 信息共享与披露</h2>
<ul>
<li>
<p>我们不会出售你的个人信息。</p>
</li>
<li>
<p>仅在提供服务所必需或法律要求时共享数据。</p>
</li>
<li>
<p>如使用第三方服务（如登录提供商），将按其协议处理必要数据。</p>
</li>
<li>
<p>Google Analytics（由 Google LLC 提供）代表我们处理使用数据。你可以通过 Google Analytics 停用浏览器插件（<a href=\"https://tools.google.com/dlpage/gaoptout%EF%BC%89%E9%80%89%E6%8B%A9%E9%80%80%E5%87%BA%EF%BC%8C%E4%B9%9F%E5%8F%AF%E4%BB%A5%E4%BD%BF%E7%94%A8%E6%B5%8F%E8%A7%88%E5%99%A8%E7%9A%84%E8%B7%9F%E8%B8%AA%E4%BF%9D%E6%8A%A4%E6%88%96%E5%86%85%E5%AE%B9%E6%8B%A6%E6%88%AA%E5%8A%9F%E8%83%BD%E3%80%82\" rel=\"noreferrer\" target=\"_blank\">https://tools.google.com/dlpage/gaoptout）选择退出，也可以使用浏览器的跟踪保护或内容拦截功能。</a></p>
</li>
</ul>
<h2>4. 数据保存与安全</h2>
<ul>
<li>
<p>我们采取合理的技术与管理措施保护数据安全。</p>
</li>
<li>
<p>数据仅在实现服务目的所需的期限内保存，或按法律要求保存。</p>
</li>
<li>
<p>敏感操作审计会记录操作类型、结果、通道和必要的账户或 OAuth 客户端归因，但不保存正文、令牌、密钥或搜索内容。IP 与设备信息在 30 天后匿名化，请求、会话和授权关联标识在 90 天后匿名化，审计事件在 400 天后删除。</p>
</li>
<li>
<p>公开个人主页的贡献统计不包含你的作业完成状态；受保护的监控端点仅导出聚合指标，不包含用户、客户端或请求标识，也不提供逐用户浏览轨迹。</p>
</li>
<li>
<p>你可以通过账户设置修改或删除部分个人信息。</p>
</li>
</ul>
<h2>5. 你的权利</h2>
<ul>
<li>
<p>你可以访问、更新或删除你的个人资料信息。</p>
</li>
<li>
<p>你可以请求删除账户及相关数据（在法律允许范围内）。</p>
</li>
<li>
<p>你可以停止使用本服务；历史公开内容可能会按平台规则继续展示。</p>
</li>
</ul>
<h2>6. 政策更新</h2>
<ul>
<li>
<p>我们可能会不定期更新本隐私政策。</p>
</li>
<li>
<p>重大变更会通过站内公告或其他合理方式通知。</p>
</li>
<li>
<p>本版本最后更新于 2026-08-09。</p>
